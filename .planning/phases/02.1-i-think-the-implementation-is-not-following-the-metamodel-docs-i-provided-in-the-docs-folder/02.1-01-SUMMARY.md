## Key Decisions

1. **Metamodel Docs as Authority:** The documentation files (`docs/01-metamodel-structure.md`, `docs/02-metamodel-relationships.md`) are the authoritative specification. Migration 009 must match exactly.

2. **CI Type Naming Convention:** Used format `EA.{Domain}-{EntityType}` where Domain is one of 8 domains and EntityType matches the metamodel doc name.

3. **Relationship Specificity:** Replaced generic ArchiMate relationships (aggregates, composes, accesses) with specific directional relationships from the metamodel graph (drives, consists_of, contains, targets, etc.).

4. **Infrastructure Preserved:** Kept ea_teams table, admin user creation, and RBAC permissions sections unchanged during migration rewrite.

5. **JSON Validation:** All optional_attributes JSONB arrays validated with `jq` to prevent syntax errors.
