<task type="auto">
  <name>Task 1: Implement CSV import backend service with gocsv parsing and validation</name>
  <files>internal/ea/import_service.go, go.mod</files>
  <action>
    1. Install gocsv dependency:
       ```bash
       go get github.com/gocarina/gocsv
       ```

    2. Create `internal/ea/import_service.go`:
       - Import gocsv, internal/ea/models, internal/ea/validation, internal/ea/repository
       - Define `ImportRow` struct: Name, CI_Type, Domain, Lifecycle_Status, Owner, Team, Attributes (JSON), Tags (comma-separated)
       - Define `ImportResult` struct: SuccessCount, ErrorCount, Errors ([]ImportError), RowErrors map[int][]ValidationError
       - Define `ImportError` struct: RowNumber, FieldName, ErrorMessage, ExpectedFormat, ActualValue

       - Implement `ParseCSV(file []byte, ciType string) ([]ImportRow, error)`:
         * Uses gocsv.UnmarshalBytes to parse CSV into ImportRow slice
         * Validates required columns exist (Name, CI_Type, Domain)
         * Validates CI_Type matches requested ciType parameter
         * Returns parsed rows or parsing error

       - Implement `ValidateRow(ctx context.Context, row ImportRow, ciType *models.CITypeDefinition, rowNumber int) ([]ValidationError, error)`:
         * Validates required fields present (Name not empty)
         * Validates CI_Type exists in database
         * Validates Lifecycle_Status exists
         * Parses Attributes JSON, validates against CI type schema (calls ValidateEntityAttributes)
         * Validates Owner exists if provided
         * Validates Team exists if provided
         * Returns validation errors list

       - Implement `ValidateImport(ctx context.Context, rows []ImportRow, ciTypeName string) (*ImportResult, error)`:
         * Fetches CI type definition from database
         * Iterates through rows, calls ValidateRow for each
         * Collects all validation errors with row numbers
         * Calculates success/error counts
         * Returns ImportResult with errors

       - Implement `BulkCreateEntities(ctx context.Context, rows []ImportRow, ciTypeName string, userID string) (*ImportResult, error)`:
         * Calls ValidateImport first, returns early if errors exist
         * Starts database transaction
         * Iterates through valid rows, calls repo.Create for each
         * Logs each creation to audit_log with batch_id
         * Commits transaction or rolls back on error
         * Returns ImportResult with success/error counts

       - Implement `GenerateErrorCSV(result *ImportResult) ([]byte, error)`:
         * Creates CSV with columns: RowNumber, FieldName, ErrorMessage, ExpectedFormat, ActualValue
         * Marshals result.Errors using gocsv.Marshal
         * Returns CSV bytes for download

       - Implement `GenerateTemplate(ciTypeName string) ([]byte, error)`:
         * Fetches CI type definition from database
         * Creates CSV with columns: Name*, CI_Type*, Domain*, Lifecycle_Status, Owner, Team, Tags
         * Adds attribute columns for all required_attributes in CI type
         * Includes example row with placeholder values
         * Returns CSV bytes for download

    **Reference:** internal/ea/validation.go for validation patterns, internal/ea/repository.go for database patterns
  </action>

<task type="auto">
  <name>Task 2: Create import HTTP handlers and integrate with EA service layer</name>
  <files>internal/api/handlers/import_handlers.go, cmd/api/main.go</files>
  <action>
    1. Create `internal/api/handlers/import_handlers.go`:
       - Import internal/ea/import_service, internal/ea/service, chi router, zerolog
       - Define request structs: GenerateTemplateRequest { ci_type }, ValidateImportRequest { file ([]byte), ci_type }, ExecuteImportRequest { file ([]byte), ci_type }

       - Implement `GenerateImportTemplate` handler:
         * POST /api/v1/ea/import/template
         * Parses ci_type from request body
         * Calls importService.GenerateTemplate(ciType)
         * Sets headers: Content-Type: text/csv, Content-Disposition: attachment; filename="ea-{ci_type}-template.csv"
         * Returns CSV file or 400 if CI type not found

       - Implement `ValidateImport` handler:
         * POST /api/v1/ea/import/validate
         * Parses multipart form for file upload and ci_type parameter
         * Reads file bytes, calls importService.ValidateImport
         * Returns 200 with ImportResult JSON: {success_count, error_count, errors: [{row_number, field_name, error_message, expected_format, actual_value}]}
         * Returns 422 if file parsing fails

       - Implement `ExecuteImport` handler:
         * POST /api/v1/ea/import/execute
         * Parses multipart form for file upload and ci_type parameter
         * Extracts user ID from JWT context
         * Calls importService.BulkCreateEntities
         * Returns 200 with ImportResult JSON showing success/error counts
         * Returns 422 if validation fails

       - Implement `GetImportStatus` handler (optional, for async import):
         * GET /api/v1/ea/import/status/{batch_id}
         * Queries import_batches table for status
         * Returns progress percentage and current step

       - Use zerolog for logging: request ID, user ID, CI type, row count, duration

    2. Wire up import routes in `cmd/api/main.go`:
       - Add import routes: POST /api/v1/ea/import/template (RequireEACreate), POST /api/v1/ea/import/validate (RequireEACreate), POST /api/v1/ea/import/execute (RequireEACreate)
       - Apply RequireEACreate middleware to all import endpoints
       - Follow existing route pattern

    **Reference:** internal/api/handlers/ea_handlers.go for handler patterns, cmd/api/main.go for route registration
