       - Implement `updateEntity(id: string, data: EAUpdateRequest): Promise<EAEntity>` - PUT /api/v1/ea/entities/{id}, returns updated entity
       - Implement `deleteEntity(id: string): Promise<void>` - DELETE /api/v1/ea/entities/{id}, throws error if relationships exist
       - Implement `listEntities(filter: EAFilter): Promise<{entities: EAEntity[], meta: PaginationMeta}>` - GET /api/v1/ea/entities with query params, returns entities with pagination metadata
       - Follow existing API service pattern from web/src/services/api.ts (error handling, JWT auth via axios interceptors)

    4. Create `web/src/stores/eaTypes.ts`:
       - Import defineStore from pinia, import eaApi from services/eaApi.ts
       - Implement state: ciTypes (CITypeDefinition[]), loading (boolean), error (string | null)
       - Implement actions: `fetchCiTypes()` - calls eaApi.listCiTypes(), caches in state, `fetchCiTypeByName(name: string)` - calls eaApi.getCiType(name), `getCiTypeByName(name: string)` - getter returning CI type from cache
       - Reuse existing CI type patterns from web/src/stores/ciTypes.ts

    5. Create `web/src/stores/ea.ts`:
       - Import defineStore from pinia, import eaApi from services/eaApi.ts, import types from types/ea.ts
       - Implement state: entities (EAEntity[]), currentEntity (EAEntity | null), loading (boolean), error (string | null), pagination (PaginationMeta), filter (EAFilter)
       - Implement actions: `fetchEntities(filter?: EAFilter)` - calls eaApi.listEntities(), stores in state, updates pagination, `fetchEntity(id: string)` - calls eaApi.getEntity(), stores in currentEntity, `createEntity(data: EACreateRequest)` - calls eaApi.createEntity(), `updateEntity(id: string, data: EAUpdateRequest)` - calls api, updates state, `deleteEntity(id: string)` - calls api, removes from state, `setFilter(filter: Partial<EAFilter>)` - updates filter state
       - Implement getters: `entitiesByDomain` - filters entities by domain, `entityById` - returns entity by ID
