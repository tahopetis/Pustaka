  <name>Task 1: Implement data quality repository queries and API handlers</name>
  <files>internal/repository/ea_data_quality.go, internal/api/handlers/data_quality_handlers.go, cmd/api/main.go</files>
  <action>
    1. Create `internal/repository/ea_data_quality.go`:
       - Import database/sql, internal/ea/models
       - Define `DataQualityMetrics` struct: TotalEntities, CompletenessPct (float64), StaleEntitiesCount, EntitiesWithErrorsCount, LifecycleBreakdown (map[string]int), ErrorBreakdownByDomain (map[string]int)
       - Define `StaleEntityCriteria` struct: DaysThreshold (int, default 90), IncludeIncomplete (bool)

       - Implement `GetCompletenessMetrics(ctx context.Context, domain string) (float64, error)`:
         * Queries configuration_items table joined with ci_type_definitions
         * Filters by ea_domain = {domain} (or all domains if empty)
         * Calculates avg(data_quality_score) where data_quality_score IS NOT NULL
         * Returns average completeness percentage 0-100

       - Implement `GetStaleEntities(ctx context.Context, criteria StaleEntityCriteria) ([]models.EAEntity, int, error)`:
         * Queries configuration_items where:
           - lifecycle_status IN ('active', 'proposed') AND updated_at < NOW() - INTERVAL '{criteria.DaysThreshold} days'
           - OR lifecycle_status IN ('proposed', 'active') AND data_quality_score < 100 (missing required fields)
         * Orders by updated_at ASC (oldest first)
         * Returns entity list with count

       - Implement `GetEntitiesWithErrors(ctx context.Context, domain string) ([]models.EAEntity, int, error)`:
         * Queries configuration_items where data_quality_score < 80 OR validation_errors IS NOT NULL
         * Filters by ea_domain = {domain} if provided
         * Orders by data_quality_score ASC (worst first)
         * Returns entity list with count

       - Implement `GetLifecycleStatusBreakdown(ctx context.Context, domain string) (map[string]int, error)`:
         * Queries configuration_items joined with lifecycle_statuses
         * Filters by ea_domain = {domain} if provided
         * Groups by lifecycle_status.name, counts entities
         * Returns map: {"Active": 150, "Proposed": 30, "Deprecated": 5, "Retired": 2}

       - Implement `GetErrorBreakdownByDomain(ctx context.Context) (map[string]int, error)`:
         * Queries configuration_items where data_quality_score < 80
         * Groups by ea_domain, counts entities
         * Returns map: {"Business": 45, "Application": 23, "Data": 12, ...}

       - Implement `GetOverallMetrics(ctx context.Context) (*DataQualityMetrics, error)`:
         * Calls all above query functions
         * Aggregates results into DataQualityMetrics struct
         * Returns combined metrics

    2. Create `internal/api/handlers/data_quality_handlers.go`:
       - Import internal/repository/ea_data_quality, chi router, zerolog
       - Define response structs: DataQualityResponse { TotalEntities, CompletenessPct, StaleEntitiesCount, EntitiesWithErrorsCount, LifecycleBreakdown, ErrorBreakdownByDomain }

       - Implement `GetDataQualityMetrics` handler:
         * GET /api/v1/ea/data-quality
         * Parses optional query params: domain (string)
         * Calls qualityRepo.GetOverallMetrics(ctx)
         * Filters by domain if provided
         * Returns 200 with DataQualityResponse JSON
         * Uses zerolog for logging (request ID, domain, duration)

    3. Wire up route in `cmd/api/main.go`:
       - Add route: GET /api/v1/ea/data-quality (with RequireEARead middleware)
       - Follow existing route pattern

    **Reference:** internal/ci/repository.go for PostgreSQL query patterns, internal/api/handlers/ci_handlers.go for handler patterns
