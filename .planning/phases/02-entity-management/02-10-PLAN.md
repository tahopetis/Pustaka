  Add onMounted hook to EntityFormView.vue to preload store data before child component renders:

  1. Import onMounted from vue:
     ```typescript
     import { onMounted } from 'vue'
     ```

  2. Add onMounted hook after existing computed properties (around line 180):
     ```typescript
     onMounted(async () => {
       // Load CI types if not already loaded
       if (eaTypesStore.ciTypes.length === 0) {
         await eaTypesStore.fetchCiTypes()
       }

       // Load EA teams if not already loaded
       if (eaTypesStore.teams.length === 0) {
         await eaTypesStore.fetchTeams()
       }
     })
     ```

  This ensures the store is populated in the parent component before DynamicFormBuilder child component mounts, eliminating the timing issue identified in verification gap 1.

  Why not use await on all calls: Check if data already exists (length > 0) to avoid unnecessary API calls when user navigates back and forth between forms.
