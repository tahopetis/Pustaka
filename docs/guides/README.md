# Guides

These guides cover the operational and contributor workflows around Porta:
installing and running the stack, reading and changing configuration, working on
the source tree, running the test suites, and contributing a change. Start with
[installation](installation.md) for a first deployment, use
[development](development.md) and [testing](testing.md) for source work, and use
[upgrading-from-pustaka](upgrading-from-pustaka.md) when moving an existing
Pustaka installation. The full documentation map is in
[the documentation hub](../README.md).

| Guide | Read it when |
| --- | --- |
| [installation.md](installation.md) | Installing with Docker Compose, finding service URLs, and signing in for the first time |
| [configuration.md](configuration.md) | Looking up an environment variable, its default, or why a key in `.env.example` has no effect |
| [development.md](development.md) | Setting up a local toolchain and running backend, frontend, or Docker commands |
| [testing.md](testing.md) | Running the Go, Vitest, and Playwright suites and understanding what CI does and does not cover |
| [contributing.md](contributing.md) | Preparing a change: conventions, security checklist, commit style, PR checks, and issue triage |
| [upgrading-from-pustaka.md](upgrading-from-pustaka.md) | Migrating data and environment variables from a pre-rename Pustaka deployment |
