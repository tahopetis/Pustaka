# API Documentation

This directory contains API documentation and specifications.

## Contents

- `api-guide.md` - Comprehensive API usage guide
- `api-examples.md` - Example API requests and responses
- `openapi.yaml` - OpenAPI/Swagger specification for all endpoints
- `postman-collection.json` - Postman collection for API testing

## Usage

Import the OpenAPI spec into tools like:
- Swagger UI for interactive documentation
- Postman for API testing
- Code generators for client SDKs
